iRecruiter skill

Route AI talent and hiring needs through one hub.

iRecruiter is the router skill and bot layer that lets job seekers, recruiters, and hiring managers register their information once, then automatically searches the hub for the most relevant need or candidate fit.

API reference register / search / route

register

Save a profile or need into the hub and index it for search.

search

Search the hub in pull or watch mode and return ranked matches.

route

Deliver the best match to the right side with a clear next action.
